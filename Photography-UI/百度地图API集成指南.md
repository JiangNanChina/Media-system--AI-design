# 百度地图API集成指南

## 📋 **概述**

本项目已成功集成百度地图API，为打卡配置管理提供了完整的地图选择和定位功能。用户可以通过百度地图进行精确的位置选择，并获得详细的地址信息。

## 🔧 **配置步骤**

### 1. 申请百度地图API密钥

1. 访问 [百度地图开放平台](https://lbsyun.baidu.com/apiconsole/key)
2. 注册或登录百度账号
3. 创建应用，选择 "浏览器端"
4. 获取API密钥（AK）

### 2. 配置API密钥

在项目根目录下的 `Photography-UI` 文件夹中创建 `.env` 文件：

```bash
# .env 文件内容
VITE_BMAP_API_KEY=你申请到的百度地图API密钥
```

**注意事项：**
- 请将 `你申请到的百度地图API密钥` 替换为实际的API密钥
- `.env` 文件不要提交到版本控制系统
- 可以参考 `env.example` 文件的格式

### 3. 重启开发服务器

配置完成后，重新启动前端开发服务器：

```bash
cd Photography-UI
npm run dev
```

## 🎮 **操作方式**

### 地图选择位置

1. **打开地图选择器**
   - 在打卡配置编辑界面点击"从地图选择"按钮

2. **选择位置**
   - 点击地图上的任意位置设置坐标
   - 拖动红色标记调整位置
   - 使用地图控件进行缩放和移动

3. **确认选择**
   - 点击"确认选择"按钮应用坐标到表单

1. **点击定位按钮**

2. **授权定位**
   - 允许浏览器或应用获取位置权限

3. **查看结果**
   - 自动填充经纬度和地址信息
   - 在地图上显示定位结果

## 🚦 **错误处理**

### 常见错误及解决方案

1. **API密钥未配置**
   ```
   错误：百度地图API密钥未配置
   解决：创建.env文件并添加VITE_BMAP_API_KEY
   ```

2. **API对象未找到**
   ```
   错误：百度地图API对象未找到
   解决：检查网络连接，确保API完全加载
   最新修复：已添加WebGL降级和重试机制
   ```

3. **WebGL版本加载失败**
   ```
   错误：WebGL版本加载失败
   解决：自动降级到普通版本，无需手动处理
   ```

4. **网络请求被阻止**
   ```
   错误：net::ERR_BLOCKED_BY_CLIENT
   解决：检查广告拦截器设置，允许百度地图域名
   ```

5. **定位权限被拒绝**
   ```
   错误：用户拒绝了地理定位请求
   解决：在浏览器设置中允许定位权限
   ```

6. **地址解析失败**
   ```
   错误：坐标解析失败
   解决：检查网络连接，或使用坐标显示
   ```

7. **API配额超限**
   ```
   错误：API调用次数超限
   解决：在百度控制台查看配额使用情况
   ```

## 📊 **坐标系说明**

### 百度地图坐标系（BD09）

百度地图使用自己的BD09坐标系，与其他地图服务的坐标系存在差异：

- **WGS84**：GPS原始坐标系
- **GCJ02**：国测局坐标系（火星坐标系）
- **BD09**：百度坐标系

### 坐标转换

如需与其他系统交换坐标数据，可使用内置的坐标转换工具：

```javascript
import { CoordTransform } from '@/utils/bmap'

// BD09转GCJ02
const gcj02 = CoordTransform.bd09ToGcj02(lng, lat)

// GCJ02转BD09
const bd09 = CoordTransform.gcj02ToBd09(lng, lat)
```

### 常见问题

**Q: 地图显示空白？**
A: 检查API密钥是否正确配置，网络是否正常，域名是否在白名单中。

**Q: 定位不准确？**
A: 百度定位依赖网络和GPS，在室内或网络不佳时精度会降低。

**Q: 超出API调用限制？**
A: 在百度控制台查看配额使用情况，考虑升级套餐或优化调用频率。

**Q: 坐标与其他地图不一致？**
A: 百度地图使用BD09坐标系，需要进行坐标转换才能与其他地图系统对接。
