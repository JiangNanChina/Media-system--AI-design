# 用户注册功能说明

## 功能概述

融媒体管理系统现已支持用户注册功能，包括成员注册和管理员注册两种类型。

## 注册类型

### 1. 成员注册
- **访问权限**: 无需特殊密钥
- **功能权限**: 设备浏览、借还管理、个人信息管理、晚自习打卡、办公室执勤等
- **注册流程**: 填写基本信息即可完成注册

### 2. 管理员注册
- **访问权限**: 需要管理员密钥
- **管理员密钥**: `PHOTOGRAPHY_ADMIN_2024`
- **功能权限**: 拥有系统全部管理权限
- **注册流程**: 需要输入正确的管理员密钥才能完成注册

## 注册页面功能

### 主要特性
1. **角色选择**: 支持成员和管理员两种注册类型
2. **实时验证**: 用户名和邮箱唯一性检查
3. **密码强度**: 实时显示密码强度指示器
4. **管理员验证**: 管理员注册需要密钥验证
5. **部门选择**: 可选择所属部门
6. **响应式设计**: 支持移动端和桌面端

### 表单字段
- **用户名**: 2-50个字符，只能包含字母、数字和下划线
- **真实姓名**: 2-20个字符
- **邮箱地址**: 有效的邮箱格式
- **密码**: 6-50个字符，支持密码强度检测
- **确认密码**: 必须与密码一致
- **所属部门**: 可选择摄影部、采编部、审核部、宣传部等
- **管理员密钥**: 仅管理员注册时需要

## 访问方式

### 1. 直接访问
- 访问URL: `http://localhost:5173/register`

### 2. 从登录页跳转
- 在登录页面点击"立即注册"链接

## 注册流程

1. **选择注册类型**
   - 点击选择"成员注册"或"管理员注册"

2. **填写基本信息**
   - 输入用户名（系统会检查是否已存在）
   - 输入真实姓名
   - 输入邮箱地址（系统会检查是否已被使用）
   - 选择所属部门（可选）

3. **设置密码**
   - 输入密码（查看密码强度指示器）
   - 确认密码

4. **管理员验证**（仅管理员注册）
   - 输入管理员密钥: `PHOTOGRAPHY_ADMIN_2024`
   - 系统会实时验证密钥正确性

5. **完成注册**
   - 点击"立即注册"按钮
   - 注册成功后显示成功对话框
   - 点击"立即登录"跳转到登录页面

## 技术实现

### 后端接口
- **注册接口**: `POST /api/auth/register`
- **密钥验证**: `POST /api/auth/validate-admin-key`

### 前端特性
- **Vue 3 Composition API**: 现代化的组件开发
- **Element Plus**: 美观的UI组件
- **表单验证**: 实时验证和错误提示
- **响应式设计**: 适配各种屏幕尺寸

### 安全特性
- **密码加密**: 使用BCrypt加密存储
- **管理员密钥**: 防止未授权的管理员注册
- **输入验证**: 前后端双重验证
- **唯一性检查**: 防止重复用户名和邮箱

## 注意事项

1. **管理员密钥保密**: 管理员密钥应妥善保管，不要泄露给无关人员
2. **邮箱唯一性**: 每个邮箱地址只能注册一个账户
3. **用户名规则**: 用户名只能包含字母、数字和下划线
4. **密码安全**: 建议使用强密码，包含大小写字母、数字和特殊字符

## 默认部门

系统预设了以下部门供选择：
- 摄影部
- 采编部  
- 审核部
- 宣传部

管理员可以在系统中添加更多自定义部门。

## 故障排除

### 常见问题

1. **管理员密钥错误**
   - 确认输入的密钥是否为: `PHOTOGRAPHY_ADMIN_2024`
   - 检查是否有多余的空格

2. **用户名已存在**
   - 尝试使用不同的用户名
   - 用户名区分大小写

3. **邮箱已被使用**
   - 确认邮箱是否已在其他账户中使用
   - 可以尝试找回密码功能

4. **密码不一致**
   - 确保两次输入的密码完全相同
